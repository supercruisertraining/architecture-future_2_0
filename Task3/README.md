## 2. Дорожная карта  

| Этап                          | Сроки        | Ключевые результаты                                                                                    | Ответственные                   | Необходимые ресурсы                           |
| ----------------------------- | ------------ | ------------------------------------------------------------------------------------------------------ | ------------------------------- | --------------------------------------------- |
| **Анализ и проектирование**   | 0–1 месяц    | - Аудит текущего DWH<br>- Определение доменов данных и ответственных<br>- Выбор технологического стека | Архитектор, CTO                 | Время экспертов, лицензии для тестирования    |
| **PoC ключевых компонентов**  | 1–3 месяца   | - MVP Data Mesh (1 домен)<br>- Настройка Kafka<br>- Развертывание Data Catalog                         | Data Engineering, DevOps        | Kubernetes, облачные ресурсы, Kafka-кластер   |
| **Self-service аналитика**    | 3–6 месяцев  | - Портал аналитики (Power BI + RBAC)<br>- Документация и обучение                                      | BI-аналитики, Security          | Power BI Premium, хостинг, учебные материалы  |
| **Масштабирование Data Mesh** | 6–9 месяцев  | - Подключение всех доменов (клиники, финтех, AI)<br>- Интеграция ML-платформы                          | Доменные команды, ML-инженеры   | MLflow/TFX, тестовые среды, Data Catalog      |
| **Миграция данных**           | 9–12 месяцев | - Перенос данных в облако<br>- Вывод из эксплуатации legacy-систем<br>- Оптимизация инфраструктуры     | Data Platform, Инфраструктура   | ETL-инструменты, DMS-сервисы, бюджет миграции |
| **Эксплуатация и развитие**   | 12+ месяцев  | - Мониторинг и SLA<br>- Расширение Data Products<br>- Контроль безопасности                            | Ops, Security, Владельцы данных | Системы мониторинга, регулярные проверки      |

### 3. Обоснование этапов  

| Этап                          | Бизнес-преимущества                                                    |
| ----------------------------- | ---------------------------------------------------------------------- |
| **Анализ и проектирование**   | Понимание текущего состояния и четкая стратегия миграции               |
| **PoC ключевых компонентов**  | Проверка архитектуры с минимальными рисками, подготовка инфраструктуры |
| **Self-service аналитика**    | Ускорение аналитики и снижение нагрузки на ИТ-отдел                    |
| **Масштабирование Data Mesh** | Гибкость и масштабируемость под новые бизнес-требования                |
| **Миграция данных**           | Снижение затрат на поддержку и повышение безопасности                  |
| **Эксплуатация и развитие**   | Стабильная работа системы и быстрый вывод новых продуктов на рынок     |
